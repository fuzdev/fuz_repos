dependency_graph.ts

Dependency graph data structure and algorithms for multi-repo publishing.

Provides the DependencyGraph class, built from local repos, with topological sort (via @fuzdev/fuz_util/sort.ts), grouping into levels, cycle detection by dependency type, and wildcard-range analysis. For the order, the levels, and the analysis workflow, see graph_validation.ts.

Detects circular dependencies, categorized by severity.

Production/peer cycles prevent publishing (impossible to order packages). Dev cycles are normal (test utils, shared configs) and safely ignored.

Uses DFS traversal with recursion stack to identify back edges. Deduplicates cycles using sorted cycle keys.

returns object with production_cycles (errors) and dev_cycles (info)

group_into_levels
#

dependency_graph.ts view source

group_into_levels(order: readonly string[], get_dependencies: (name: string) => Iterable<string>, names?: ReadonlySet<string>, rank?: ReadonlyMap<string, number>): string[][]

Groups names into levels by their longest dependency path: a name's level is one past the deepest of its dependencies in names, and dependencies outside names don't count. So a level's names never depend on each other, and each depends only on names in earlier levels — work within a level can run in parallel. Within a level, names follow rank when given (config order, say), else order.

import {group_into_levels} from '@fuzdev/fuz_repos/dependency_graph.js';
